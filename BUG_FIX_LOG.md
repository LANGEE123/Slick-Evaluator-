# BITS Digital CodeForge V1.0 — Official Bug Fix Log

| # | Bug / Issue Identified | How User Reproduced It | Root Cause | Fix Implemented | How User Tested the Fix |
|---|---|---|---|---|---|
| **1** | Course dropdown duplicates course options when uploading files sequentially | Uploaded an Excel file, then uploaded another file (or re-uploaded the same file) | Existing `<option>` elements in the `<select id="course">` dropdown were not cleared prior to reading and populating courses from the new file | Cleared `course.innerHTML` back to the default placeholder (`<option value="">Select a course to begin</option>`) before reading incoming workbook data | Uploaded `bits_sample_standard.xlsx` followed by `bits_sample_multi_course.xlsx`; verified that the course list was completely reset and populated only with courses from the active file |
| **2** | Course dropdown repeatedly lists duplicate course options for every student row in the dataset | Uploaded an Excel file with multiple student rows for the same course (e.g. 45 students in "CS F111") | The code executed `data.map(d=>d.Course).forEach(c => course.add(new Option(c,c)))` directly on student records without deduplicating course names | Extracted unique course titles using `[...new Set(data.map(d => d.Course).filter(Boolean))].sort()` before creating dropdown options | Uploaded a sheet containing 45 students in `CS F111`; verified `CS F111` appears exactly once in the select element |
| **3** | File picker filter accepts only legacy `.xls` files, preventing selection of `.xlsx` | Clicked "Choose File" on modern browser / OS file picker; standard Excel `.xlsx` files were filtered out | The input element specified `accept=".xls"` rather than including modern Excel `.xlsx` MIME and extension types | Updated attribute to `accept=".xlsx, .xls"` | Opened file selector; verified that `.xlsx` files are selectable and load properly |
| **4** | Minimum and Maximum statistic cards display inverted values in the UI | Selected a course with varied student marks (e.g., Min 25, Max 98) | DOM element IDs were swapped in the HTML (`<div class="stat">Min<br><b id="max"></b></div>` and `<div class="stat">Max<br><b id="min"></b></div>`). Furthermore, `computeStats()` assigned `min.textContent = m[0]` and `max.textContent = m[m.length-1]` to the swapped IDs | Aligned DOM IDs with labels (`stat-min` and `stat-max`) and correctly mapped lowest score to Min and highest score to Max | Loaded test dataset; verified Min card displayed `25` and Max card displayed `98` |
| **5** | Statistical computations produce `NaN` and crash when course has 0 student records | Selected an empty course or a course with no student marks | Division by zero in average calculation (`0 / 0 = NaN`), accessing `m[0]` on an empty array produced `undefined`, and median calculation failed | Implemented empty-data guard clauses: if `m.length === 0`, display graceful placeholders (`—`) for min, max, avg, and med | Tested by selecting an empty course; verified UI displays `—` without `NaN` or unhandled exceptions |
| **6** | String concatenation corrupts Average, Median, and Bell Curve calculations when marks are formatted as text in Excel | Uploaded an Excel file where marks were stored as text cells (e.g. `"80"`, `"70"`) | In JavaScript, `reduce((a, b) => a + b, 0)` treats string values as string concatenation (`0 + "80" + "70"` = `"08070"`), resulting in an average of `4035` | Sanitized input by explicitly coercing marks to numbers using `Number(val)` and validating with `Number.isFinite()` | Injected string marks into test data; verified class average calculated correctly to `75.00` |
| **7** | Bell curve rendering throws `NaN`/`Infinity` and crashes when all students have identical marks | Uploaded a course where every student received the exact same score (e.g., 85 marks) | When all scores are identical, standard deviation $\sigma = 0$. The Gaussian formula `(1 / (\sigma \sqrt{2\pi})) * e^{-0.5((x-\mu)/\sigma)^2}` evaluates to `1/0 = Infinity` and `NaN`, breaking canvas path operations | Added a check for `std === 0` (or `std < 0.001`); if detected, renders a discrete indicator line at the mean rather than attempting invalid zero-division curve math | Uploaded `MATH F111 Uniform` (all 85 marks); verified the chart renders safely without canvas errors |
| **8** | Timer starts running immediately upon page load instead of active grading session, and delays first second | Opened the HTML page and left it idle for 3 minutes before choosing a course | `gradingStartTime = Date.now()` was initialized on script load; `setInterval` waited a full 1000ms before first DOM paint, leaving clock blank or stale | Initialized timer only upon active instructor course selection, and triggered an immediate `renderTimer()` tick before the interval begins | Opened page, verified timer starts fresh from `00:00` upon course selection and advances smoothly every second |
| **9** | Uncaught `TypeError` when clicking "Reset Range" before course selection, and redundant double `confirm()` prompts | Clicked "Reset Range" on page load without selecting a course | Two consecutive `confirm()` modals were called sequentially. If `buildGradeUI()` had not yet generated the select elements, `document.getElementById(g + "min")` returned `null`, crashing on `.value` assignment | Replaced double prompts with a single clear modal/confirmation, and verified that DOM elements exist before attempting to reset values | Clicked "Reset Range" prior to selecting a course; verified graceful feedback with zero console errors |
| **10** | Cascade Max logic assigns invalid negative value (`-1`) to grade dropdown when previous min is 0 | Reduced a grade minimum boundary (e.g., `D min`) to 0 | `cascadeMaxFrom` computed `prevMin - 1` = `-1`. Since dropdown options are bounded between `0` and `100`, setting `.value = -1` left the dropdown in an unselected/invalid state | Clamped cascaded max bounds to `Math.max(0, Math.min(100, prevMin - 1))` | Set a grade minimum to 0; verified subsequent grade maximum clamped to `0` cleanly |
| **11** | Uncaught `TypeError` when canceling out of the browser file picker dialog | Clicked "Choose File" and clicked "Cancel" without picking a file | `e.target.files[0]` was undefined; `r.readAsBinaryString(undefined)` threw `TypeError: Failed to execute 'readAsBinaryString' on 'FileReader': parameter 1 is not of type 'Blob'`. Additionally, `readAsBinaryString` is deprecated | Added early guard `if (!e.target.files || !e.target.files.length) return;` and updated FileReader to modern `readAsArrayBuffer` with `XLSX.read(data, {type: 'array'})` | Opened file dialog and cancelled; verified zero exceptions thrown in developer console |
| **12** | CSV export unescaped fields cause structure corruption and URL object memory leak | Downloaded CSV multiple times; exported courses or instructor names containing commas | Fields were concatenated without RFC 4180 quoting; multiple downloads created orphaned `blob:` URLs without calling `URL.revokeObjectURL()` | Implemented RFC 4180 escaping (wrapping fields with commas or quotes in `""`) and added `setTimeout(() => URL.revokeObjectURL(a.href), 1000)` cleanup | Exported course named `"CS F111, Comp Programming"`; opened in Excel and verified proper column delineation |
| **13** | Incomplete range validation allows ungradable gaps at top (100) and bottom (0) of scale | Configured A max to 90 and E min to 10; system reported valid ranges | `validateRanges()` verified only internal adjacency (`max === prevMin - 1`), failing to check if the overall range encompassed the full [0, 100] academic scale | Added validation constraints: Grade `A max` must equal `100` and Grade `E min` must equal `0` | Tested with `A max = 95`; verified system flagged "Grade scale must cover full 0–100 range" and disabled export button |
